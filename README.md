# Chat-Paper

AI RAG 論文聊天系統

> 提供多種輸入方式，支援 RAG 分塊切片與關鍵詞檢索，讓 AI 引導您的學術思維。
> 

## 使用說明

1. [**開啟網站**](https://chat-paper-omega.vercel.app/)
2. **請先配置 Gemini API 金鑰 (免費版或付費版都可以)，如果沒有可以到 [Google AI Studio](https://aistudio.google.com/api-keys) 申請**
3. **上傳論文**
    1. 上傳論文 PDF
    2. 貼上論文文字
    3. 範例論文《Attention Is All You Need》
4. **等待論文讀取…**
5. **論文重點分析**
    1. 論文標題
    2. 作者團隊
    3. 論文摘要簡介 (Abstract)
    4. 四大核心發現 (Key Takeaways)
6. **論文完整原文**
    1. 論文原文和頁數
    2. 選取原文並一鍵提問
7. **論文聊天室**
    1. 推薦延伸問題
    2. 自行輸入問題
8. **AI 回答**
    1. 支援 Markdown 語法
    2. 附上 RAG 檢索來源（點擊跳轉至論文原文對應的片段並高亮提示）
9. **RAG 設定**
    1. 段落長度 (Chunk Size)
    2. 重疊字數 (Overlap)
10. **更換論文**
    1. 回到首頁
